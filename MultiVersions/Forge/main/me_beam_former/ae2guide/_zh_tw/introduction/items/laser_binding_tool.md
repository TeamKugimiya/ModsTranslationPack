# 光束綁定工具

<ItemImage id="me_beam_former:laser_binding_tool" scale="4" />

用於綁定／解除綁定
- 全向光束成型器（雙向）
- 無線能源塔（雙向）
- 無線能源塔至機器（單向，需有能量介面）

## 操作方式

- Shift + 點擊右鍵：綁定來源設備（全向／能源塔）。
- 點擊右鍵：與目標設備建立／中斷連線。
- 空手 Shift + 點擊右鍵：清除已綁定的設備。
