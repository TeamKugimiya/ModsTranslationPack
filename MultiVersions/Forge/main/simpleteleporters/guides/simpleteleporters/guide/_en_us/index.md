# Simple Teleporters

Welcome to Simple Teleporters! This mod provides easy-to-use teleportation mechanics for Minecraft.

## Features

<Row>
<Column>

### Teleporter Network

Create a network of <ItemLink id="simpleteleporters:teleporter" /> blocks linked by <ItemLink id="simpleteleporters:ender_shard" /> items to quickly travel between locations. Upgrade to an <ItemLink id="simpleteleporters:enhanced_ender_shard" /> for cross-dimensional travel!

</Column>
<Column>

### Personal Teleportation

Use the <ItemLink id="simpleteleporters:hearth_crystal" /> to save a personal home location and teleport back to it from anywhere.

</Column>
</Row>
