《起源科技》提供了多種適合工廠建築的強化板方塊。

它們很適合拿來做地板、牆面與機械外殼。

所有強化板都附有**半磚**、**階梯**與**壓力板**變體。

### 強化板種類

*   **[銅強化板](@oritech:machine_plating_block)**：標準的機器外殼用強化板。  
　表面平整俐落，與《起源科技》的機器外觀非常搭配
*   **[鐵強化板](@oritech:iron_plating_block)**：顏色較深、質感粗獷的工業級強化板，  
　適合重工業區與結構支撐區
*   **[鎳強化板](@oritech:nickel_plating_block)**：色澤較亮、帶有微黃金屬感且耐腐蝕的強化板，  
　很適合無塵室或專業設備區
*   **[碳纖維板方塊](@oritech:carbon_plating_block)**：現代感較強、深色且高強度的板材，  
　適合拿來做對比或高階設施的深色區塊
