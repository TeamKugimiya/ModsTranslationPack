機器核心會決定《起源科技》多方塊機器的品質。

更高階的核心不會自動讓機器變快，  
它們的主要用途是提升機器可支援的擴充器數量，以及可連接的升級插件規模。

#### 製作階段
- 機器核心是分階段製作的，每提升一階就會提高可達成的機器品質上限
- 第 1 階使用木材與工作台
- 第 2 階使用銅或鐵搭配青金石
- 第 3 階使用[碳纖維束](@oritech:carbon_fibre_strands)或[鎳錠](@oritech:nickel_ingot)搭配紅石
- 第 4 階使用[銅強化板](@oritech:machine_plating_block)與[終界複合材料](@oritech:enderic_compound)
- 第 5 階使用[精金錠](@oritech:adamant_ingot)與[高級運算引擎](@oritech:advanced_computing_engine)
- 第 6 階使用[耐用金屬錠](@oritech:duratium_ingot)與[可疑容器](@oritech:dubios_container)
- 第 7 階使用[普羅米修斯錠](@oritech:prometheum_ingot)與[超導體](@oritech:superconductor)

#### 使用方式
- 當你對多方塊機器按右鍵時，它會醒目顯示所有需要放置核心的位置
- 你也可以直接手持核心對機器按右鍵，  
　只要目標位置沒有障礙物，系統就會自動放置下一顆可用核心
- 最終形成的機器品質，影響的是擴充器外接數量，與升級插件可擴展程度，  
　而不是單純的處理速度

若要查看機器的最終品質，可將滑鼠移到介面左上角的機器圖示上。

若你完全不打算使用升級插件，通常也可以選擇成本最低的核心來完成組裝。
