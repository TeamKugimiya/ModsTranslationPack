資源節點是原料的無限來源，可透過[基岩鑽礦機](@oritech:deep_drill_block)開採。

這些節點嵌在基岩中，本身無法被破壞。

若要尋找它們，請先在地表尋找[礦物與礦物巨石堆](@oritech:deepslate_platinum_ore)。

巨石堆會標示出正下方基岩層附近的資源節點位置。

<center>

</center>

資源節點包含多種材料，  
例如鐵、銅、金、鎳、鉑、鈾，甚至像鑽石這樣的稀有寶石。

要開採這些節點，鑽頭必須一路延伸至基岩層。
