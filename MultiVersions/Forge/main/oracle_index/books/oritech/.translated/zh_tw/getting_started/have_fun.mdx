走到這裡，你已經擁有往不同方向發展所需的核心基礎了。

接下來不錯的發展方向包括：
- 建立更完整的物流與供電網路。
- 擴展到龍門架自動化，以及以機器框架為核心的農場系統。
- 投資[多方塊結構]($MULTIBLOCKS)與[升級插件]($ADDON_CONCEPTS)。
- 朝[核反應爐]($NUCLEAR_REACTOR)或[粒子加速器]($PARTICLE_ACCELERATOR)邁進。
- 等資源流穩定後，開始研究賽博改造。

把手冊其他部分翻一翻，選一條你最有興趣的方向，開始讓你的工廠走向專精化吧。
