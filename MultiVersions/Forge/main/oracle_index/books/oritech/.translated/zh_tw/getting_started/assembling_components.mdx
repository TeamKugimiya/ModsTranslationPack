你的下一個重要目標，是建造一台[組裝機](@oritech:assembler_block)和一台[離心機](@oritech:centrifuge_block)。

組裝機在製作許多元件時，效率都比手工合成高得多，  
而且有些零件若不用它，根本無法正常製作出來。

離心機則負責整條科技樹都會依賴的資源轉換流程，
包括處理礦物碎塊、製作碳纖維，以及在裝上適當的升級插件後進行流體加工。

這兩台機器都需要 RF 能量，而且在你理解[升級插件]($ADDON_CONCEPTS)後，實用性還會再提升一大截。
