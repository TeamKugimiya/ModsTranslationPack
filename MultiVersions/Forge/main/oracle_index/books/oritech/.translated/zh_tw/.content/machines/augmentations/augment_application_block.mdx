賽博生化改造中心是研究與安裝身體永久升級的主要設施。

這些改造能提供各種好處，從被動屬性提升到全新的能力都有。

<Callout variant="warning">
    只要你曾在某一刻深刻體會到血肉之軀的脆弱，  
    那麼你就是《起源科技》最理想的客戶。  
    鋼鐵帶來力量與穩定，而我們很樂意替你補上這一步。

    但也請記住，一旦踏上機體改造之路，幾乎就沒有真正的回頭路。  
    這些改造皆為永久性強化，  
    你之後可能會不自覺地把昔日同伴稱作「簡陋生物質」。
</Callout>

## 研究與開發

若要開始使用，請直接走進已組裝完成的**賽博生化改造中心**。

這會打開研究介面，讓你瀏覽並啟動各種研究計畫。

每項改造都需要特定的能量與材料，材料可以來自玩家物品欄，  
也可以來自機器的內部儲存空間（可透過介面存取）。

許多高階改造都需要先完成前置研究，這些相依關係會顯示在科技樹中。

改造中心同時也是**研究站**的主機，研究站會以多方塊附屬模組的形式安裝上去。

主機最多支援 **3 座研究站**，因此可以同時進行平行研究。
*   每座研究站都需要 **3 個機器核心**
*   每座研究站一次只能處理 **1** 項研究任務

## 安裝與控制

研究完成後，對應的改造就能進行安裝。

安裝時需要再支付一次性材料成本，才能把這項技術永久融合到玩家身上。

若玩家身上已經有改造，也可以透過介面左下角的**匯入**功能，把它們掃描進這台機器。

### 改造管理

這些強化原本就是為永久使用而設計，不需要維護，也不需要持續供能。

不過若某些能力太干擾日常活動（例如**礦物視野**或高速移動類能力），  
你仍可隨時開關功能。

*   **切換選單**：按住機體改造快捷鍵（預設為 **[G]**）可打開圓盤介面，  
　把游標移到想開關的改造上並放開，即可切換狀態
*   **移除**：雖然改造是以永久使用為前提設計，但必要時仍可移除；  
　不過安裝時投入的資源不會返還

### 給模組包開發者的資訊

《起源科技》的改造系統完全由資料驅動，也可透過資料包高度自訂。

*   **屬性調整改造**：改變實體屬性，例如速度、觸及距離或生命值
*   **狀態效果改造**：賦予類似藥水的效果
*   **客製化改造**：提供獨特邏輯，例如礦物視野；資料包可引用這些項目，但底層邏輯仍需由 Java 模組實作

現有改造可以被修改、停用，也能透過 JSON 定義全新的改造。
*   **定義範例**：[Attack Damage Augment (GitHub)](https://github.com/Rearth/Oritech/blob/1.21/fabric/src/main/generated/data/oritech/recipe/augment/attackdamage.json)
*   **紋理路徑**：`oritech/textures/gui/augment`

新增客製化改造時，也別忘了補上對應的翻譯項目。
