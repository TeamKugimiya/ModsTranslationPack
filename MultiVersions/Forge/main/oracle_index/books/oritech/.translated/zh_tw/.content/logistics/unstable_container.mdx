薛丁格的保險箱用於儲存極大量的 RF。

手持此物品，對著 TNT 或核爆物之類的不穩定方塊點擊右鍵  
（完整清單請參見遊戲內的工具提示），該方塊就會被收納進保險箱中。

原始方塊越危險，保險箱最終能擁有的儲能容量就越高。

這個多方塊結構不需要機器核心，會自行完成組裝。

能量會從頂部與底部的中心方塊輸出，其餘位置則都可輸入能量。

UI 會顯示內含方塊、雷射加成，以及輸入／輸出資料。

### 過載充能

若想進一步提高保險箱的可儲能上限，可以讓[終界雷射](@oritech:laser_arm_block)持續指向它。

雷射並不會直接把能量傳進保險箱，而是改為提升它的容量上限。

指向保險箱的雷射越多、射速越快，可額外提升的容量也越大。

這種增長是指數級的，因此最終容量可以非常驚人。

這些額外容量只會在雷射持續指向且正常發射時存在。

一旦雷射耗盡能量或停止運作，儲能上限就會緩慢下降，回到原本的基礎值。
